# Unishka Bisht — Portfolio

A personal developer portfolio showcasing my projects, skills, and journey as a Full Stack Developer.

**[Live Demo](https://portfolio-unishkabisht-s27e.vercel.app)**

## Preview

- Hero section with typewriter animation
- About, Skills, Projects, Resume, and Contact sections
- Responsive design with mobile hamburger menu
- Smooth scroll and reveal animations

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript
- Google Fonts (Inter, Playfair Display)
- Font Awesome Icons
- Deployed on **Vercel**
